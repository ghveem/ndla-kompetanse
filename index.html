Kodeoversikt — kompetansemålkodar og læreplanar

Sporar status og endringar i Udir sitt Grep-register, og syner kva NDLA-artiklar som er merka med kodar som er utgåtte eller erstatta.

Automatisk generert kvar veke ved å samanlikne nytt Grep-uttrekk mot førre. Nyaste øvst.

Korleis dette fungerer

Ein planlagt jobb i GitHub Actions hentar data frå Udir sitt Grep REST-API kvar veke, avgrensar det til berre dei faga NDLA dekker, normaliserer det og samanliknar med førre uttrekk. Endringar (nye kodar, kodar som vert sett til utgått, og kodar som vert erstatta av andre) hamnar i endringsloggen. Data vert lagra som JSON-filer i repoet, så heile historikken er sporbar via Git.

«Artikkel-sjekk» søker automatisk opp NDLA-artiklar merka med utgåtte eller erstatta kompetansemålkodar (KM), kjerneelement-kodar (KE) og kompetansemålsett-kodar (KV), via NDLA sitt eige search-api (parameteren grep-codes). Ingen manuell eksport er nødvendig — dette køyrer som ein del av den same vekentlege jobben.
