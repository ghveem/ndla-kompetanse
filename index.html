Sporar status og endringar i Udir sitt Grep-register, og syner kva NDLA-artiklar som er merka med kodar som er utgåtte eller erstatta.

Automatisk generert kvar natt ved å samanlikne nytt Grep-uttrekk mot førre. Nyaste øvst.

ArtikkelKM-kodar i bruk

Korleis dette fungerer

Ein planlagt jobb i GitHub Actions hentar data frå Udir sitt Grep REST-API kvar natt, normaliserer det og samanliknar med førre uttrekk. Endringar (nye kodar, kodar som vert sett til utgått, og kodar som vert erstatta av andre) hamnar i endringsloggen. Data vert lagra som JSON-filer i repoet, så heile historikken er sporbar via Git.

«Artikkel-sjekk» samanliknar KM-kodane redaktørane har brukt til å merke NDLA-artiklar (frå eit eige eksport-steg, sjå README) mot statusen i Grep, og flaggar artiklar som må ryddast opp i.
